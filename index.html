C#Booru Download GitHub

C#Booru is a lightweight, cross‑platform image management application inspired by the structure and workflow of traditional boorus. It is built with C# and Avalonia, and uses a SQLite embedded database to store posts, tags, and collections efficiently.

Supported formats

Type Extensions
Images .bmp, .ico, .jpeg, .jpg, .png, .webp,
Moving images .gif
Videos .avi, .mkv, .mp4, .webm
